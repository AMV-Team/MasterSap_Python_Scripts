# Security Policy

## Reporting a Vulnerability
Se ritieni di aver trovato un problema di sicurezza (es. script che può causare comportamenti dannosi, leak di dati, ecc.):
- **NON** aprire una Issue pubblica con dettagli sensibili.
- Contatta i maintainer a: **assistenza@amv.it**
- Includi:
  - link allo script (percorso nel repo)
  - versione MasterSap
  - passi per riprodurre
  - impatto stimato

## Disclosure
Valuteremo la segnalazione e, se necessario, pubblicheremo una nota di sicurezza dopo la correzione.

## Notes
Questo repository contiene script: usa sempre cautela ed esegui in ambienti controllati prima di applicare a progetti reali.
