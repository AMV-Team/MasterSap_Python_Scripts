# Community Scripts

Questa cartella contiene script condivisi dalla community AMV.

## Scopo
Raccogliere script utili, esempi pratici e automazioni create dagli utenti o dai collaboratori del progetto.

## Caratteristiche
Gli script presenti in questa cartella:

- possono essere utili e funzionanti
- non sono ancora verificati formalmente da AMV
- possono avere limitazioni legate a versione, ambiente o convenzioni locali
- devono comunque essere documentati in modo chiaro

## Requisiti minimi per i contributi
Ogni script inserito in questa cartella deve avere:

- file Python `.py`
- intestazione standard completa
- descrizione chiara dello scopo
- indicazione di input, output e limitazioni
- assenza di dati sensibili o di clienti

## Nota importante
Gli script in `community/` sono forniti "as is".
Prima dell'uso in produzione, è consigliato verificarli nel proprio ambiente di lavoro.

## Evoluzione verso verified
Uno script può essere promosso in `verified/` dopo revisione tecnica e verifica interna.
