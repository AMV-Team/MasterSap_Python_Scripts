# Community Scripts

Questa cartella contiene script condivisi dalla community AMV.

## Caratteristiche
- utili ma non ancora verificati formalmente da AMV
- possono contenere limitazioni o dipendenze specifiche
- devono includere intestazione standard e descrizione chiara

## Requisiti minimi
- file `.py`
- header completo
- nessun dato cliente
- spiegazione di input, output e limitazioni

## Nota
Gli script presenti in questa cartella sono forniti "as is".
