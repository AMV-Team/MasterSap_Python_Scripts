# MasterSap_Python_Scripts Community (Apache-2.0)
Scripts repository: a public library of MasterSap Python scripts and examples contributed by users, for users.

Benvenuto/a! Questo repository raccoglie **script Python** per automatizzare e velocizzare attività in **MasterSap**:
- esempi didattici (cartella `examples/`)
- contributi della community (cartella `community/`)
- script verificati e mantenuti (cartella `verified/`)

> **Nota importante**
> - Questo repo contiene **solo script**. Non include bridge/server MCP o componenti eseguibili lato AMV.
> - Gli script della cartella `community/` sono contributi di terzi: **non garantiamo** che siano corretti o adatti al tuo caso.
> - Gli script in `verified/` sono quelli che AMV ha testato/curato.

## Come partecipare
- **Domande, idee, showcase:** usa **Discussions**
- **Bug/requests concreti:** apri una **Issue**
- **Contributi di codice:** invia una **Pull Request**

Vedi: CONTRIBUTING.md

## Struttura del repository
- `examples/` — esempi piccoli e robusti
- `community/` — script della community
- `verified/` — script “AMV Verified”
- `docs/` — linee guida e FAQ

## Compatibilità
Ogni script deve dichiarare:
- versione MasterSap testata
- unità (m/cm)
- scopo, input, output, limitazioni
