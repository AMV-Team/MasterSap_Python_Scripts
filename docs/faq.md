# FAQ

## Che differenza c'è tra examples, community e verified?
`examples/` contiene esempi didattici ufficiali di AMV.
`community/` contiene script condivisi ma non verificati formalmente.
`verified/` contiene script validati da AMV.

## Come eseguo uno script?
Apri la console Python MasterPy di MasterSap e lancia lo script seguendo le istruzioni del file.

## Cosa devo scrivere nell'header?
Titolo, autore, licenza, versione testata, unità, scopo, input, output, limitazioni.

## Posso caricare uno script con dati di un cliente?
No.

## Come faccio a sapere se uno script è affidabile?
Controlla se è in `verified/` e su quale versione è stato testato.
