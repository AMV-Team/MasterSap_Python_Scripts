# AMV Verified Scripts

Questa cartella contiene script controllati e approvati da AMV.

## Significato di verified
Uno script presente in questa cartella è stato esaminato e ritenuto adatto come riferimento più affidabile rispetto ai contributi community.

## Criteri minimi
Per essere inserito in `verified/`, uno script deve avere:

- header completo e coerente
- scopo chiaramente descritto
- input e output documentati
- limitazioni esplicitate
- test sulla versione di MasterSap dichiarata
- comportamento ripetibile
- assenza di dati sensibili

## Processo tipico
1. lo script nasce come esempio o contributo community
2. viene revisionato tecnicamente
3. viene verificato internamente
4. viene promosso nella cartella `verified/`

## Obiettivo
Fornire una raccolta di script più stabili, leggibili e riutilizzabili.
