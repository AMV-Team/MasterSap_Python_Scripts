# AMV Verified Scripts

Questa cartella contiene script controllati e approvati da AMV.

## Criteri minimi
- testati su versione MasterSap dichiarata
- header completo e coerente
- input/output documentati
- comportamento ripetibile
- nessun dato sensibile

## Processo
1. proposta iniziale in `community/`
2. revisione tecnica
3. verifica interna
4. promozione in `verified/`
